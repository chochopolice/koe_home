# こえホーム（音声で操作するホーム画面・MVP）

高齢の方向けの Android ホームアプリです。画面は1枚だけ。大きな「話す」ボタンを押して話しかけると、声で返事をして操作します。

## できること

| 言い方の例 | 動作 |
|---|---|
| 「〇〇さんに電話かけて」「むすこに電話」 | 復唱して確認 →「はい」で発信 |
| 「山田さんに電話したい」（山田さんが複数） | 「山田さんは3人見つかりました。1番、…。どなたに電話しますか？」→ 名前か「2番」で選ぶ |
| 「写真見せて」または「🖼 写真を見る」ボタン | 案内の読み上げと同時に Google フォトを開く。案内は「写真を開きます。写真を検索する場合は、『オーケー、グーグル』と呼びかけてから、お話しください」。Google フォトが無い端末では、こえホーム内で新しい順に表示 |
| 「去年の桜の写真を見せて」など条件つきの写真 | Google アシスタントに引き継ぐ（音が鳴ったら、もう一度同じ言葉を話す） |
| 「アシスタント」 | Google アシスタントを呼び出す |
| 「ラインを開いて」または「LINE を開く」ボタン | LINE を開く（LINE が入っている端末だけボタンが出る） |
| 「グアムの天気は？」「昨日の日経平均は？」「〇〇を調べて」 | アプリ内に Google の検索結果を大きめの文字で表示。「調べて」と言わなくても、ほかの操作に当たらない言葉はそのまま検索する（v0.11）。「下」「上」「前」「とじる」 |
| 「いま何時？」「今日は何日？」 | 読み上げ |
| 「やめる」「もどる」 | いつでも最初の画面へ |
| 「終了」「いつもの画面」 | こえホームをとじて、いつものホーム画面へ |
| 「使い方」 | 話しかけ方の案内 |

声が通らないときのために、連絡先の ★（お気に入り）の人が大きなボタンで並びます（最大5人）。

## APK の作り方（どちらか）

**A. Android Studio**
1. このフォルダを Android Studio で開く（初回は部品のダウンロードで数分かかります）。
2. スマホを USB でつなぎ、▶ Run。

**B. GitHub Actions（PC に開発環境を入れない場合）**
1. このフォルダを GitHub の非公開リポジトリに push（ブランチ名 `main`）。
2. Actions タブ →「Build APK」→ 完了した実行の Artifacts から `koehome-debug-apk` をダウンロード。
3. 中の `app-debug.apk` をスマホに送ってインストール。

## スマホ側の初期設定（家族が1回だけ行う）

1. アプリ「こえホーム」を開き、マイク・連絡先・電話・写真の許可をすべて「許可」。
2. 使い方を選ぶ。
   - **ふつうのアプリとして使う（v0.2 からの標準）**：ホームアプリは今までのものを「常時」に。
     初回に出る案内から「他のアプリの上に重ねて表示」を許可すると、**画面を点けるたび（ロックがあれば解除後）**に自動で開きます（v0.3）。
     通話中・着信中は開きません。常駐のため、通知欄に「こえホーム」の通知が出続けます。
     「✕ とじて、いつもの画面へ」ボタン、または「終了」と言うと、直前のアプリかいつものホームに戻ります。
     自動で開くのを止めるとき：時計を長押し →「画面を点けるたびに開く」をオフ。
     数日たつと開かなくなる場合：設定 → アプリ → こえホーム → バッテリー →「制限なし」に。
     許可の画面でオンにできない場合：設定 → アプリ → こえホーム → 右上の ⋮ →「制限付き設定を許可」をしてからやり直す。
   - **ホーム画面そのものにする（高齢の方の専用機向け）**：ホームボタン →「こえホーム」→「常時」。
3. 連絡先アプリで、よくかける相手に ★ をつける。
4. 呼び名で探せるようにする：連絡先の「ふりがな」と「ニックネーム」を入力（例：ニックネームに「むすこ」）。
5. 設定 → テキスト読み上げ で日本語の音声が入っているか確認。
6. 画面ロックは「なし」か指紋・顔認証に（PIN があると電源投入後にこの画面まで進めません）。

## 家族向けメニュー

**画面上部の時計を長押し** → アプリ一覧／Android の設定／ホームアプリの切り替え／連絡先の再読み込み／自動で開くための許可／画面を点けるたびに開く（オン・オフ）。
元のホーム画面に戻すときは「ホームアプリの切り替え」から。

## ボタンのアイコン

`app/src/main/res/drawable-nodpi/` の `ic_call.png`（電話）、`ic_home.png`（とじる）、`ic_photo.png`（写真）。同じ名前の PNG（透過・正方形）で上書きすれば差し替わります。

## 調整できる値

`MainActivity.kt` 末尾の `companion object`：読み上げ速度、聞き直し回数、ボタンに出す人数、写真の枚数、検索結果の文字の大きさ。
言い回しの追加は `Commands.kt` の単語リスト。

## 既知の制約

- 音声認識は端末の Google 音声認識を使用。機種によっては通信が必要です。
- 名前の照合はあいまい検索です（v0.7）。姓だけ・名だけ・名前の一部でも当たり、1文字ちがい（3文字以上）や
  漢字のゆれ（斉藤／斎藤、渡辺／渡邊、高橋／髙橋 など）も同じ名前として扱います。
  ただし音声認識は漢字で返すため、連絡先がカタカナやローマ字だけで登録されている人は当たりにくいです。
  その場合は連絡先の名前を漢字にするか、ニックネームに漢字の呼び名を入れてください。
- 110・119 はアプリから直接発信できません（OS の制限）。
- アシスタントが出ないとき：設定 → アプリ → 標準のアプリ → デジタルアシスタント アプリ が「なし」になっていないか確認。呼び出し後、画面下に「アシスタント呼び出し：（方法名）」が出ます。
- Google アシスタントへは「呼び出し」だけで、聞いた言葉は渡せません（言い直しが必要）。引き継いだ後は こえホーム の外の画面になります。
- 着信に声で出る機能、LINE、天気は未対応。
- Web検索は結果を画面に出すだけで、内容の読み上げはしません。開いた先のサイトの広告や偽の警告は防げません。
- 写真は端末内のものだけ（クラウドのみの写真は対象外）。
- 写真が1枚〜数枚しか出ないとき：写真の許可が「選択した写真のみ」になっています。設定 → アプリ → こえホーム → 権限 → 写真と動画 →「常にすべて許可」に。
